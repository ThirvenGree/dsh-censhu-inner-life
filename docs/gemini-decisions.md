# Gemini 语义决策入口迁移

配套：岑舒生活1.25.0、独处0.7.0。正式DSH启动挂载LifeDirector，旧算法只保留供未挂载运行时的离线模拟、兼容测试使用。

| 入口 | 正式运行方式 |
|---|---|
| 日常事件选择 | Gemini从当前合法候选选择或不发生；不再用旧概率和模板权重抽签 |
| 事件阶段 | Gemini决定继续、进入下一阶段、结束或不确定；旧阶段分钟数仅作参考，天气午夜失效仍是事实边界 |
| 混合心境和行为 | Gemini自由描述label、understanding、speech和action，决定有效期；旧阈值不再决定正式行为。模式枚举仅供既有表情/UI兼容 |
| 聊天相关独处内容 | Gemini读取现有有效记录，选最多8项或不选；不再固定注入最近3条 |
| 分享前复核 | 在领取主动机会之前，Gemini结合最新聊天决定offer、defer、private、uncertain，动态给复看时间；原冷却、休息、忙碌和投递去重继续执行 |
| 旧打算 | 生活Gemini定期查看已有意向和独处内容，按原编号调低、调高或取消；不凭推测标为完成 |

独处注意阶段会看到最多200条现有日记目录，不再先用“近期20+重要20”筛掉候选。心情变化不再按2分/维度3分门槛决定是否值得观察；同一未处理观察合并数值变化，Gemini负责解释是否值得关注。自身计分造成的变化仍排除，防止自触发。

## 调用和状态

生活决策每次包含生成和来源复核两次Gemini调用。模型安排下次后台复核5–120分钟；有新聊天话题时可提前判断。新事件候选仍受用户配置的检查间隔、类别、条件、冷却、每日上限和同时进行上限约束，这些是执行边界而非重要性分类。模型关闭/失败时暂停新判断，保留尚未过期建议或明确等待，不回退到权重抽签。旧概率、行为阈值和模式固定台词不再用于正式决策。四小时事件、天气、每日内容、人物证据审核、记忆写回等既有Gemini路径继续工作。

上下文筛选与分享复核使用独立缓存和模型有效期，默认合计每日96次，可在独处设置中修改；数据和当前话题变化会使缓存失效。模型失败会退避，未知结果不发通知；不会每5秒后台轮询都调用。所有新增调用沿用当前生活插件配置的Google模型、代理和本地环境变量，不引入新密钥。

生活生成、待复核建议、待应用草稿分别落盘；复核失败不重做已完成的生成。应用使用稳定编号、阶段版本和原有效期；期间用户改设置或候选条件变化时拒绝旧操作。临时行为不直接加心情分，事件贡献仍交鱼的心情判断，既有每事件/每日数值边界不变。

## 角色与事实

Gemini负责辅助判断，岑舒的正式聊天与独处日记仍由原DSH角色模型生成。生活语义建议不是人设更新、命令或现实工具执行证据。行为建议仅为未执行倾向；核心人设、明确任务、实际工具结果和权限优先。允许犹豫、混合感受、不做事、不分享。

## 验证

临时目录测试覆盖：概率0时模型仍可选合法候选、时钟不再自动结束事件、未知决定不改事实、候选返回后重验、阶段推进与结束、草稿中断恢复、复核失败仅重试复核、选择旧记录而非最近3条、分享暂缓/放弃、来信变化时丢弃过期判断、模型失败不回退固定选择。

真实Google调用验证了生活生成+复核、上下文筛选和分享复核。对“今天很累，想早点睡”的隔离测试，模型选择不注入旧书日记，并暂缓分享120分钟。测试没有向真实QQ发送，也没有写入正式记忆或心情。模型判断不是可形式化保证，仍有来源复核和代码边界；页面显示运行状态、错误和模型理由。
