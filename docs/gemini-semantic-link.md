# Gemini 语义联动更新（2026-10-30）

生活 1.27.0 / 独处 0.9.0。

- 已提及判断：实际可见回复及成功的 QQ 文字发送先进入持久队列，等待至少 5 秒后每批最多 8 条由 Gemini 判断；可识别改写，输入只包含发送原文和当时的候选。只接受本批编号与真实原文摘录。失败延后重试，不用关键词补判；队列上限 200 条，24 小时过期，不阻塞对话。设置页可见待处理数和错误。
- 独立规划：生活决策读取独立的有效独处目录和自身积累，不使用聊天筛选后的子集。私密想法可以改变自己的安排，不代表获得分享许可；失效、撤回、被拒绝的记录不参与。
- 自身积累：Gemini 可以按现有编号保留、更新、撤回和合并，独立审核后应用。合并保存来源，保留操作只更新复核时间；容量不足会显示未接纳原因，不静默吞掉新项。核心角色保护及主档 64 条上限不变。
- 项目进展：计划、进行、完成、暂缓、放下、不确定由模型判断。输入增加绑定会话中宿主观察到的成功工具结构化文件/图片回执、既有画画回执和模拟生活事件。只保留产物路径或编号，不保存任意工具输出、环境变量或凭据。模拟生活事件不能证明现实工具完成；完成状态必须引用真实回执，再由审核模型确认与项目匹配。
- 新完成回执会触发一次积累复核，即使没有新日记；已处理编号不会反复触发。旧工具结果不全量扫描，未支持的非结构化回执不会被猜测成完成。
- 暂缓分享：模型给出的复看时间早于缓存期限时，复看时间优先。仍遵守休息、聊天避让、限额及失败重试。

调用增量：可见消息的提及判断每批一次；积累生成和独立审核沿用两阶段调用，新增完成回执可触发该流程；生活规划复用原生活决策调用，不为每条私密想法额外开一轮。

验证包含模拟回归，以及隔离临时目录中的真实 Gemini 提及判断、项目合并和独立审核。测试不修改正式角色卡或发送 QQ。
