# 性格发展

生活 1.28.0 / 独处 0.10.0。性格主档是独处插件的 personality.json；与生活积累、真实用户记忆分开。

Gemini 综合生活观察、审核过的独处记录、角色自身提案，以及已安装记忆插件可读取的相关记忆，提出保留、更新、撤回、继续观察或不确定。再由独立模型审核决定是否采用。状态、形成原因、有效期（1–180天）和复看周期（1–90天）、综合考虑间隔（1–720小时）均由模型决定；这些边界只控制格式和资源，不用来推断性格。

界面：独处插件新增“性格发展”独立栏，展示来源原文、状态、期限、复看时间、读取覆盖、历史及重试按钮。她可通过 censhu_personality 工具主动提出方向；用户也可在页面提出。提案不直接改人设。观察中和不确定的条目不注入行为。

来源：指定记忆文件、各插件运行时上下文，以及 memory/de_memory、Engram、MDCG、OpenViking、Mnemon 的可用只读接口。Mnemon 受其活动 Memory Space / pinned view 约束；OpenViking 有原生只读召回兜底。未安装、未就绪、未提供接口或读取失败的来源会明确显示；成功来源仍采用。不承诺扫描全部记忆或越过来源自身权限。

防自证：生成的性格主档与投影标为 personality-evolution，不写入用户事实记忆；记忆证据入口排除这一来源和已知性格原文。模型同时检查性格总结的转述与主观日记，不能拿旧结论或自身提案证明新性格。审核输入移除角色卡内自动生成段。原始证据随条目保存；本次未召回不是删除证明。

生效：仅将审核通过且有效的 tentative / established 条目同步到 Cosplay 行为中的独立管理段及生活 profile.personalityDevelopment。手动角色卡、身份、职业、关系和权限优先；并发手动编辑触发重新审核。生活决策、主会话和独处上下文读取这一投影，不改原有人设正文。

故障：模型失败不走规则生成；同步失败保留阶段，只重试同步；额度/配置类4xx暂停生成，修复后点击“重新考虑 / 重试”。到期、关闭后清除投影（需要原角色接口可用），主档保留历史。读取、生成、审核在后台空闲时执行，设置页GET不触发调用。
