# 独属于她的跨日生活积累

主档唯一保存在独处插件目录 `personal-growth.json`，不是生活插件的真实记忆人物演化条目，也不是用户记忆库。包含最多64项自身偏好、习惯、私人项目或物件想法，以及形成时间、审核时间、来源快照、模型建议复核时间和最近200批修改记录。

新审核通过的独处日记，以及绑定会话主动调用 `censhu_self_develop` 提交的想法，都可以进入Gemini生成与独立审核。允许没有变化、不确定或不采纳；新增、修改、撤回由模型决定。长期积累跨日保留，复核日期到达不会自动删除；有到期项时每天最多发起一批周期复核。安装前的全部日记不会集中回灌；可以通过工具主动提出已有想法。

审核通过后自动同步两处投影：

- dsh-cosplay 当前岑舒角色的 behavior 字段中独立标记区，只写本主档的补充，不替换手动行为、核心身份、职业、关系、规则或权限。
- 生活插件 profile.selfDevelopment，参与上下文和Gemini事件/行为判断。不是 evolvingFacts，不作为青枔真实记忆证据，也不参与旧的真实记忆人物演化自证。

原始记录、后续改主意和审核记录由独处主档管理，两个投影由同一份主档更新。首次同步绑定角色编号；切换角色时暂停，避免写到其他人物。角色卡在审核后发生手动变化时拒绝旧结果，撤回尚未同步的候选主档修改并重新审核；不覆盖手动更新。同步前保存投影备份，服务暂时不可用会单独重试同步，不重新生成内容。

她可以有自己的未来项目与喜好，但计划不等于完成、想拥有不等于已经购买，生成图也不是实拍。没有真实工具或生活记录时，审核不能把现实动作当作已执行。积累不增加青枔事实，不扩大关系和授权。关闭“跨日自身积累与审核同步”停止新的自动更新；已审核稳定积累保留，可通过后续审核提出撤回。

设置页展示主档项目、状态和同步错误。`censhu_self_develop read`读取，`propose`提交最多500字的自身想法，经模型审核后同步；工具不能直接任意改角色卡。

验证包括主档持久化、未通过审核不改设置、生成/审核/同步各阶段故障恢复、Cosplay手动内容保留、过期审核拒绝、标记损坏拒绝及撤回投影。真实Gemini隔离测试把“想画窗台植物小画册”保留为尚在构思的私人项目，没有写成已完成；测试未修改实际角色。
