# 岑舒独处生活 · dsh-censhu-inner-life

一个独立的 DSH 感知插件。岑舒不在聊天时，也可以经历生活、产生感受、留下简短日记和形成尚未执行的打算。分享只是后续选择。

## 运行过程

1. 岑舒生活插件在事件开始、每个阶段和结束时写入持久化变化流；普通阶段可以积累，心情和灵感也会进入待感知队列；近期聊天只作为有上限的短期快照，不逐条写入变化流。
2. Gemini 使用已有本地环境变量和生活插件模型设置，合并决定现在关注、稍后再看、只记下来或暂不确定。
3. 需要关注时，在独立的原生 DSH 会话里运行一轮，沿用全局 cosplay 人物设定与主会话所选模型。传入相关生活、记忆和最近独处记录，不复制整段 QQ 历史。
4. 这轮只输出愿意留下的感受、短日记与打算，不记录提供商内部推理，不直接执行对外工具。
5. Gemini 核验来源。审核通过后，临时倾向进入共享生活上下文；重要自身记忆交给现有记忆写回队列，新且未计入的感受交给“鱼的心情”统一处理。
6. 如果她愿意分享，向主会话投递有明确来源的内部通知，仍受现有共同主动冷却与忙碌状态约束。主会话可用原工具准备图、查资料、发任意形式的 QQ 内容，或什么也不做。独处回合提出的 draw/read/remember 都是打算，不能显示为已执行。

## 依赖与安装

需要 DSH 原生 `sessionController.create/resolveAgent`、`agent.followup/whenIdle` 和岑舒生活 **1.20.0+** 的 `cenShuLifeShared` v2 接口。接口变化会显示故障，不回退读取私有会话缓存或 bridge 状态文件。

本机安装：`node scripts/install.mjs`，然后重启 DSH。设置 → **岑舒独处生活**。默认已启用；生活主会话必须已绑定并载入。

配置与状态保存在 `$DSH_HOME/censhu-inner-life`。不保存 API key。Gemini 调用由生活插件的现有环境变量、代理与模型设置负责。

## 默认节奏

- 合并窗口 120 秒；判断至少间隔 20 分钟。
- 每日最多 12 次注意判断、6 次独处回合。每个独处回合另有一次 Gemini 来源审核。
- 02:00–06:00 休息；待感知队列 500 条。队列满则保留生产者游标，暂缓读取新项。
- 下次考虑时间由模型给出窗口，再随机选择并持久化；重启不重抽、不重新从头计时。
- 暂缓与不确定保留原始记录；网络失败按 15 分钟、1 小时、6 小时退避。配置错误暂停，可手动重试。
- 主会话忙碌时排队，不打断回复。正常聊天、DSH 与 Pet 通过已有共享上下文读取临时状态。

这些是调用与运行边界；具体感受、是否思考、有效期、后续打算与分享意愿交给模型。设置页可调整节奏。

## 去重与恢复

事件观察编号、读取游标、处理状态、日记来源、各会话读取回执与分享投递记录分别保存。日记先落盘，再写回心情和记忆；同一记录重复重试不会重复建立候选。分享入队前保存投递身份，崩溃时不盲目重发 `dispatching` 状态，设置页可以看到。

心情变化已经计入时只做感知，不能给同一事件再计一次。自身经历与主观认识明确标注来源，不作为青枔的真实事实；稳定人设仍由 cosplay 和已有记忆维护。

## 开源参考

已研究并下载 AIRI 与 Stanford Generative Agents 的相关源码。没有可直接装进 DSH、同时联动现有生活/鱼的心情/记忆/QQ/Pet 的现成插件，因此本项目为原创 DSH 适配实现，参考其独立后台会话、经历流、反思与规划分离的设计，并未复制第三方源码。详见 [调研记录](docs/research.md)。

## 0.2.0：学习高星项目后的改进

- 参考 Generative Agents / AI Town：把同一事件的阶段组织成经历时间线。注意判断同时选择本轮 focusIds 与历史 recallIds；旧的重要日记也能被回想，未选中的变化保留排队。不新增向量库，不为每条变化另开评分调用。
- 参考 AIRI 上下文来源管理：模型可以明确用新认识替代旧的临时感受与打算。旧日记保留，旧倾向停止注入，尚未投递的旧分享机会一并取消。
- 参考 AIRI 后台任务隔离：不同反思批次使用新的原生 DSH 会话；同一批次可恢复仍可用的会话；失败会话单独隔离。仅将审核通过且模型选中的旧日记带入下一批，避免被拒候选与诊断内容积累成新的人设。保留最近3个会话，较旧的插件自建会话通过 DSH 原生接口归档，不删除日志，不归档主会话。
- 注意判断、独处生成、来源审核逐阶段保存。审核网络失败或重启后只重试审核，不重新生成日记，不重复消耗已完成阶段的配额。来源会话解绑或记忆/心情写回开关改变时放弃旧候选，原观察保留；队列上限、节奏和调用配额的修改保留审核检查点。
- 真正没有内容的独处结果静默确认观察，不创建空日记、不发通知，也不再调用一次空内容审核。
- 主会话忙碌只排队，不算模型故障、不消耗独处回合额度；未变化状态不重复写盘。

设置页显示处理检查点、回想来源数量、重要性、临时状态被替代情况及独处会话归档记录。具体情绪、关注内容、回想哪些经历和何时再思考，仍由模型判断。

延后审核不延长临时感受的寿命：有效期从原生成时间计算。审核恢复时已经过期的日记只保留历史，不补发分享、不补计过时情绪。

## 0.3.0：隔离、计分与积压修复

- 创建原生会话前先持久化隔离身份；安装脚本为当前安装的 OpenViking、灵枢、Mnemon、Engram、记忆演化、鱼的心情添加会话隔离。未经审核的日记不进入这些插件的自动采集或评分。设置页验证协议与源码摘要；升级覆盖适配后暂停独处，运行 `node scripts/install-isolation.mjs` 修复并重启。适配不认识的新版本会报错，保留备份，不盲目修改。
- 自身记忆带 `character-life` 标记；人物演化排除该来源，包括旧中文来源标签和写回账本中的文字。新的独处记忆只能引用本批有编号的生活事件，不能引用旧独处记忆自我强化。
- 事件观察带抽样反应、计分状态、候选和回执。独处新感受按原始 eventId 去重；原事件反应不重复计分；允许审核确认的独立反思新感受，每个原事件最多一次，配额未接纳的事件不能补计。每日绝对心情贡献不超过 6，各维不超过 12，可调低。这个上限独立于日常生活/天气的既有计算。
- 自身心情变化不会再触发下一轮独处；真实聊天期间的心情变化也不进入独处队列。真实来信后默认避让 10 分钟；最近 8 条、最长 2 小时的短期聊天快照用于理解背景。
- 待感知项默认 48 小时过期，包括未采用的旧项；过期审核检查点也清理，游标照常推进。旧逐条聊天项不再提交模型。
- 画画灵感由原插件独占分享，独处只感知，不重复递交分享机会。内部唤醒使用 plugin 来源，鱼的心情不把它当成真人发言。
- 选择最近真实来信的已绑定会话，不再固定第一项；桌宠活跃时共享临时状态，不将分享通知转投 QQ。无真实活跃信息时使用原绑定会话。
- 正常保留最近 3 个原生独处会话；归档接口失效时停止扩建并在设置页报错，最多保留 6 个未归档会话，不丢失旧会话的跟踪记录。

## 0.3.1：共同适配与独处新感受

隔离安装不再依赖生活适配添加的来源列表。两套显式安装脚本在验证对方协议与隔离守卫后，共同登记最终文件摘要；健康检查本身不改摘要，未知源码变化仍会报错。支持任意安装顺序，修复后重启 DSH。

独处审核接收原事件反应、最新计分回执和候选接纳状态。Gemini 必须指明原事件、准确引用本轮反思，并解释新增感受与原反应的区别；不能区分时不给额外分数。只对已被日常心情流程接纳的事件提供这条路径，日常配额挡掉的事件不能借独处补计。独处贡献仍按原事件最多一次，并受独立每日绝对总量限制；不阻止原生活事件的后续阶段。

## 0.3.2：升级后可分别恢复适配

鱼的心情升级后两套补丁都丢失时，任一安装脚本可以先修复自己。缺失的对方适配只会跳过登记刷新并提示继续修复，不中止本次安装，不删除旧登记，也不把缺失功能标为正常。运行另一套安装脚本后，两边的最终摘要同步恢复。

诊断结果显示创建独处会话时请求的编号、实际返回编号以及相等校验；编号在创建前预登记，仍严格拒绝使用未预登记的不同编号。新感受继续由模型辨别是否独立产生，不仅因情绪方向相同就减分；每件事一次和每日绝对总量上限保留。

## 0.4.0：独处可以调整生活意向

独处模型在本轮 lifeIntentions 快照中选择现有编号，通过 intentionChanges 提出 lower / raise / cancel 和理由。Gemini 在原有来源审核中返回 approvedIntentionIds；只提交已批准且确在快照中的建议。生活插件校验生成批次、逐项版本、有效期、调整方向和实际事件关联；不能新造意向、改时间/文字/模板，也不能取消已经发生的事件。结果和拒绝理由保存在独处条目中，失败不会冒充成功；记录重试不会重复调整。

每日内容生成也能读取当前有效的独处感受与打算，标注 character-life，不作为人物演化的事实证据。主会话读取两者时，以生活插件当前意向状态为准，并共同遵守生活意向的 mayMention 标记。

DSH 返回不同会话编号时，先持久化身份故障并阻止后续自动创建。只有原生会话清单确认是新建、位于独处私有目录、空白且空闲的会话，才登记为插件所有并归档。旧会话、主会话和不能确认归属的会话不会归档；无法安全清理时保持暂停，设置页显示原因。归档成功后可通过手动重试再检查一次，不自动循环新建空会话。


### 0.4.1 实际意向权重回执

配合生活插件1.21.0，设置页显示每条已采用调整的实际模板乘数变化。单条意向已调高但被其他取消或暂缓意向挡住时，明确展示未提高的实际权重；这些回执也进入独处临时上下文。


### 0.5.0 分项联动与中断恢复

参考流行项目的持久化步骤与能力协商，记忆、心情、意向调整各自保存回执；一项失败不阻止其他项，重试沿用原编号。心情候选写盘中断可恢复且不重复扣额度，过期的临时效果不补发。独处页面显示各项状态；不增加模型调用。配套版本：生活1.23.0、独处0.5.0。[研究来源、适用边界和验证](docs/research-durable-effects.md)。


### 0.6.0 Gemini 逐项注意与事件现状

生活提供只读事件现状与阶段来源，独处由Gemini分别决定关注、暂缓、只记下或不确定，并选择复看时间；新变化不再被其他条目的暂缓挡住。遗漏项保留，决定跨重启，设置页显示理由。原休息与预算边界继续生效。[研究、真实调用与验证](docs/research-attention.md)。


### 0.7.0 Gemini生活与情境决策

正式路径的日常事件选择/阶段推进、混合心境、独处上下文筛选、分享前复核和旧意向重估均改为Gemini判断。旧概率和行为阈值仅保留离线对照。新增待复核持久化、失败退避和独处每日96次情境调用预算（可调）；保留授权、配额、去重及事实核验。[实际调用、边界与测试说明](docs/gemini-decisions.md)。


### 0.8.0 独处主档的跨日生活积累

自身偏好、习惯、私人项目与物件想法由独处插件统一保存，经Gemini生成与独立审核后自动同步Cosplay和生活插件补充区。支持角色自主提议、跨日保留、模型复核、调整和撤回，保留来源/修改记录，不改核心身份或用户事实。[主档、同步和验证说明](docs/personal-growth.md)。
